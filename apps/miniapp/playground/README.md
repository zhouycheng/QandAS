# 答题布局交互草稿

草稿固定采用已选定的 A 版。左侧提供题目场景、反馈方式、屏幕尺寸和阅读字号配置，右侧切换布局编辑与模拟答题。默认采用顺序模式，确认作答后在选项下方显示详解。

预览入口：`http://127.0.0.1:5186/`。

## 启动

在本目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

使用 React 18.3.1、Vite 7.3.6，锁文件沿用管理端已验证的依赖版本。本次通过 pnpm 本机缓存离线安装。

## 体验

1. 在布局编辑页点击右侧顶部按钮切换模式。顺序模式中比例杆禁用，模块仍可排序；自定义模式保留比例。抓住模块标题旁的六点把手拖动，键盘聚焦后也可用上下方向键排序。
2. A 版右侧依次为模式按钮、比例杆和预览按钮。点击模式按钮直接切换顺序／自定义。保存后刷新保留布局设置，恢复默认需再次保存。
3. A 版点击预览进入答题界面；通过上方“布局编辑”返回并保留布局草稿。题号计时栏与工具栏固定，题干及选项占中间内容区。
4. 即时反馈下，单选选择答案、多选点击底部“确认答案”后，在四个选项下方直接显示正确答案、你的选择和“试题详解”。题干、选项及工具栏保留，继续向下滚动阅读。阅读题的详解在当前小题浮层内，紧跟选项显示。未确认作答及交卷后反馈不提前显示答案和详解。可在左侧“反馈方式”切换验证。

5. 五组题目均包含 A～D 四个选项，提供学习计划、完整学习记录、长选项对照、多选与阅读材料。比较小屏、标准屏、大屏与五档字号。A 版顺序布局下，普通题的题干与选项自然接续，长内容在同一个区域滚动。阅读题默认显示圆形悬浮“选项卡”按钮，环形进度按本篇已确认作答的小题数／总小题数计算。点击按钮后隐藏入口并展开占内容区 65% 的小题面板，顶部细杆可拖动调整至内容区 35%～90% 高度，右上角关闭按钮收起面板。小题切换统一使用页面底部“上一题／下一题”；多选未确认时，右侧为“确认答案”，确认后恢复切题。阅读示例包含三道小题，切换小题或关闭面板保留答案、进度与原文阅读位置。自定义比例布局继续保留。

A 版拖拽解析由 `src/main.jsx` 中带注释的 `A_DRAG_ANALYSIS = false` 停用，原面板、方向设置和手势代码保留供比较；此前的备选实现保留在源码中。

布局设置保存在浏览器 `localStorage`，键名前缀为 `qanda-layout-playground:`。模拟作答状态在切题时重置。纠错与答题卡显示入口演示提示，收藏与标记提供当前页面状态反馈。

## 验证

```sh
pnpm test
pnpm build
```

浏览器检查使用本机已有 Playwright 和 Chrome；启动开发服务器后运行：

```sh
# PLAYWRIGHT_MODULE 指向本机 Playwright 包，已安装到当前环境时可省略。
node tests/browser.mjs
```

浏览器脚本覆盖 A 版选项下方显示详解、答案高亮、顶部及底部区域位置不变、题干与选项连续阅读、普通题连续滚动、阅读题圆形入口、浮层高度拖动、右上角关闭、底部确认及三道小题的作答进度、15 组尺寸／题目场景、5 组交卷后反馈场景。预览截图在 `previews/`。

正式小程序迁移在选版后进行。浏览器验证覆盖网页原型；微信真机的 WXS 事件、键盘与触控手感需在迁移阶段验收。
