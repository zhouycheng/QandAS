# Manage a question bank

1. Discover tools on the requested connection. When the connection or a required grant is missing, follow [user authorization](references/authorization.md) before continuing.
2. Before any import or upload, [confirm the course, bank and chapter](references/destination.md) with the user.
3. For original materials or supplied packages, load the companion `qanda-question-bank` skill and review the content. Use the host's skill loader or read the skill and its references through MCP resources. The workbench download at the MCP origin's `/qanda-bank-skills.zip` provides the same resources and runnable validator.
4. Read the guide for the operation: [create a question or reading group](references/question.md), [edit a question](references/edit.md), or [preview and commit a ZIP](references/import.md).

Return the actual receipt, available question/revision IDs, skipped items and unresolved source locations. Publish only on explicit request with the required grant.
