# 验收规范

## 验收证据

每次本地或 CI 验收应记录提交 SHA、日期、环境、执行命令和结果，并区分通过、失败、跳过及未观察范围。运行报告与去敏证据保存在忽略目录；本文件定义可复用的验收入口和业务范围。

## 自动检查

共享包执行 `npm --prefix packages/content-format test`。管理端在 `apps/admin` 执行 `pnpm test` 和 `pnpm build`，包含 TypeScript 未使用检查。

小程序在 `apps/miniapp` 执行 `npm run build`、`npm test`。编译检查调用微信官方 WXML / WXSS 编译器，分别核对进程失败、模板行列诊断及样式 `ERR`。本机未安装编译器时的跳过状态必须单独记录。

后端在仓库根目录执行：

```sh
node apps/api/scripts/backend.mjs test
node apps/api/scripts/backend.mjs verify
```

完整验收使用隔离 PostgreSQL、RabbitMQ、Redis、Prometheus 和邮件捕获容器。合同、HTTP Schema 和 Postman 的生成检查见[接口验收入口](../apps/api/acceptance/README.md)。测试报告与去敏运行证据放在 Git 忽略目录，记录实际执行范围。

## 业务回归

核对邮箱／微信首次登录自动建号、绑定冲突、测试账号固定登录码、账号资料与注销、公开目录与分类筛选、内容检测、导入发布、所有题型、联合题库、即时及统一反馈、计时、错题收藏、自评、统计、公告群码、反馈和管理监控。同步核对重复提交、账号切换、迟到响应和存储失败。

管理员编辑、导入和发布覆盖权限、业务版本、内容校验及幂等重试。用户内容检测覆盖邮箱独立上下文、版本变化、私有媒体取件、签名及密文校验、回调重复／乱序和注销后的迟到任务。真实微信接口、平台回调登记和真机结果与本地提供端测试分别记录。

反馈未读覆盖题目纠错和缺课需求：处理中回复、修改回复及处理状态变化触发提醒，原样保存保持版本和时间；批量已读校验归属、数量、重复 ID 和版本边界，整批失败回滚，旧版本确认保留新回复。跨会话及分页检查摘要、未读标记和更新时间排序。小程序检查三处红点联动、屏幕外记录、部分可见长回复、底部遮挡、切分类、翻页、后台及账号切换，失败后重试保留幂等键。观察器测试与微信开发者工具、真机的实际可见性检查分别记录。

单设备恢复覆盖离开页面、切后台、重启、断网作答和响应丢失；其他设备不能编辑进行中的练习。游客额度、偏好和布局分别验证。

答题布局覆盖旧偏好缺省顺序模式、两种模式间保留比例、四模块排序、原子保存失败和未保存预览隔离。按所有题型检查即时／统一反馈的详解揭晓、多选确认与末题交卷、答对自动下一题及稀疏页面更新。阅读题覆盖同材料修订进度、65% 初始高度、35%～90% 拖动、取消恢复、关闭重开、跨小题记忆和键盘恢复。微信开发者工具按小屏、标准屏、大屏与五档字号检查长题滚动、富文本图片、填空／简答输入、试答及正式练习恢复；真机手势与键盘单独验收。

错题收录覆盖即时确认后收录、草稿排除、非即时交卷后收录、本机与云端去重、已有错题掌握状态更新，以及筛选与重练范围一致。正式成绩和累计答题量保持交卷统计，交卷重试沿用第一次提交的内容和幂等键。收藏始终立即保存。核对通用设置的浅色选项外框同时作用于答题和布局预览；列表触底追加、下拉刷新、失败重试和筛选重置分别验证。

暂停消费者后，进度应可靠积压；恢复后按原命令确认。重复消息仅落库一次，暂时故障超过八次仍持续自动重试。交卷排在此前保存任务之后，恢复后只保存一份客户端成绩；响应丢失、进程重启、过期发布租约和 Redis 缓存清空均须核对完整任务及结果。队列与监控均属于核心验收范围。

`ContentRedisPostgresTest` 使用真实 Redis 和 PostgreSQL，核对缓存命中后的题目、答案隐藏、交卷与成绩；内容版本更新、下架和个人进度应及时反映。回滚事务不得发布可复用版本号的缓存，Redis 超时应回源并恢复。该测试上下文在类结束时关闭，避免额外消费者干扰队列暂停用例。`RequestAdmissionTest` 覆盖等待容量、时限、线程中断、许可回收和探针独立性。

## 性能记录

同一环境、相同数据量比较 20、100、1000 题：微信实际包体、请求数、`setData` 字节数、SQL 次数和响应时间。管理端比较入口及业务异步块。容量检查独立记录 HTTP 接收、队列积压、消费及落库速率和延迟。

Node 数据量测量不能代替真机流畅度，浏览器构建结果不能代替页面检查。真机触摸、键盘、原生返回、长期断网恢复及容量压测分别记录实测结果。

## 微信与发布待验项

- 真实微信文本检测通过案例，以及邮箱登录账号独立检测上下文的实际结果。
- 媒体公网取件、平台回调登记、签名加密配置及真实媒体回调闭环。
- 真机分享落地、输入焦点、触摸、原生返回、长期断网和注销后的本机清理。
- 实际运营主体、类目、备案、合法域名、内容版权、隐私指引和审核体验；协议待发布事项见[用户协议与隐私政策](legal-documents.md)。

自动验收使用本地提供端、捕获邮件和隔离容器。真实提供端、平台配置及生产环境的结论分别记录。

## 本地练习补充验收

按[本地练习](local-practice.md)检查微信加密存储、题目与答案修订配套、本地交卷及统计去重。云端接受结构正确但与标准答案不同的判定，读取结果应保持客户端判定。新建练习取得新内容，当前练习和历史成绩保持原修订。数据库使用当前结构直接初始化，旧数据清空后运行匹配客户端。

## 同步与查询优化验收

`SyncAdmissionTest` 检查提交和恢复查询的独立预算及异常回收。`BackendOptimizationPostgresTest` 使用真实 PostgreSQL 验证失败任务隔离、稀疏保存读取量、轻量回执和三十天正文保留，并用冻结的原查询对照当前统计结果。累计一千、一万、十万条作答分别记录 `EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)`，证据位于忽略目录 `.backend-runtime/sync-query-optimization/`。SQL 观察覆盖 JDBC 实际执行次数，同时单列 MyBatis 次数和条目返回行数；远端容量单独验收。
