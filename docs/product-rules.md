# 产品规则

题小搭面向课程复习，包含微信小程序、内容管理端和后端，应用版本为 `1.0.0`。

## 目录与访问

学院、专业、年级用于题库分类。筛选保存在当前设备，默认全部；重置按钮清空筛选，再次点击恢复上次条件。切换学院清除不适用专业。分类为空表示通用题库；同一分类记录内共同匹配已选条件，未限定维度视为通用，多条记录取并集。

游客与不同账号使用相同的公开条件：课程启用、题库启用且发布、存在有效作答题目；阅读小题同时要求材料启用。分类只影响目录和搜索，公开内容可按 ID 直接打开。停用、下架和归档保留已有练习的固定修订、成绩、反馈及历史引用。章节只允许删除空章节。

邮箱验证码或微信验证成功直接登录，首次使用自动创建账号。邮箱、微信绑定冲突明确拒绝；更换邮箱验证新旧邮箱并撤销旧会话。资料保留昵称、头像和账号绑定。管理员使用独立密码登录。测试账号规则见[测试账号管理](test-accounts.md)。

邮箱或微信首次建号时，后端从六款官方默认头像中等概率随机分配一款并保存；再次登录读取已保存头像，已有账号保留当前头像。个人资料页通过微信原生头像选择器更换头像，经内容检查后保存。

小程序底栏包含首页、题库、复盘、我的四个等宽入口。首页学习入口下方提供答题卡片：当前设备有未完成练习时继续答题，否则可通过两列联动选择最近练过的科目和题库，创建新答题；没有练习记录时进入题库。新答题采用设置页指定的默认预设，反馈方式和出题顺序使用预设配置。题库保留左侧科目、右侧统计与章节列表；学院、专业、年级三个筛选位于题库搜索框下方。复盘优先显示错题、收藏与重练。

## 练习与结果

支持单选、多选、判断、填空、简答和阅读题组；阅读题量按小题计算。普通、随机和模拟练习按完整题组选择；错题和收藏可选择小题并携带材料。同科目可以联合多个题库，每次最多 1000 道作答题。

题库章节正文和搜索结果使用全局默认预设直接开练；尾部调节图标打开本次答题配置。章节题数紧跟标题，以空格分隔并显示为灰色。常规练习中，蓝色整科卡片点击打开配置，卡片尾部显示“整科练习”。预设在“答题偏好 → 默认答题配置”中管理，可命名、新增、编辑、删除及指定默认；默认预设先更换再删除。初始为“日常练习”：练习模式、即时反馈、顺序出题、20 题、不限时。预设保存模式、反馈方式、出题顺序、题量和时长，选择题库、章节、错题范围不进入预设。配置弹层中独立一行选择预设及保存当前配置，开始答题按钮单独占满一行。手动修改后标记自定义；点击“保存为预设”直接新增并选中，练习预设名称按“模式·反馈方式·顺序 - 题量档位 - 时长”生成，例如“练习·即时反馈·顺序 - 全部 - 不限时”；模拟考和背题使用“模式 - 题量档位 - 时长”。题量按当前选项从少到多命名为 1档、2档、3档等，最高项为“全部”；列表仍展示实际题量摘要，名称可在预设列表编辑。按模式、反馈方式、出题顺序、请求题量和时长判断配置是否重复；快捷保存遇到已有配置时直接选中已有项并保留名称，预设列表新增或修改时拒绝与其他预设配置重复。保留全局默认项，保存失败保留当前配置。预设保存请求题量，例如请求 20 题、当前仅有 8 题时仍保存 20；主动选择“全部”才保存全部。

题量按当前范围的实际题数生成档位，最高档为“全部”；不足指定题量时使用全部题目。超过单次 1000 题时禁止选择全部并提示缩小范围。普通和模拟练习完整保留阅读题组，实际题量调整时明确说明。答题时间直接选择不限时、10、20、35 分钟或自定义 1～1440 整数分钟，背题不限时。模拟考支持不限时，交卷后统一揭晓；背题直接展示答案和解析。

首页模拟考先进入题库选择章节。左侧科目用于切换右侧章节列表；点击章节、搜索结果或顶部整科卡片，以所选范围的全部题目和固定 45 分钟直接开考，不弹出配置，也不修改默认预设。整科卡片覆盖当前科目的全部题库；章节和搜索结果隐藏配置图标。退出选择、离开题库 Tab 或成功开考结束选择状态，切到后台保留状态。单次题量超过 1000 题时保留现有上限并提示缩小范围，不截取部分题目冒充全部。

创建时固定题目、顺序、内容修订、反馈模式和计时配置。即时反馈确认客观作答后，正确答案、自己的答案和“试题详解”紧接选项显示，题干和选项保留，滚动位置保持；填空详解接在题干输入内容之后，阅读小题详解位于浮层内部。未确认草稿隐藏判题资料，统一反馈在交卷后显示，背题直接展示答案与详解。多选未确认时底部右键为“确认答案”，没有选项时禁用，确认后恢复“下一题”或末题的“交卷”；模拟考和交卷后反馈直接切题，交卷时统一确认草稿。填空逐空匹配，全部空位正确才判整题正确，沿用填写后确认流程。已作答的简答题交卷后显示“这道题掌握了吗？”，可选择“已掌握”或“还需复习”，也可不选。选项使用紧凑列表，多选标识为小圆角方形，单选和判断为圆形。翻题按钮约 40px、工具项约 32px 高，保留安全区。答题卡在答题过程中始终可用。

阅读题首次进入材料时，内容区底部居中显示 64px 圆形“选项卡”，无遮罩；进度环统计本次练习内相同材料修订的小题，即时反馈计入已确认作答，模拟考和交卷后反馈计入已有内容的草稿，并提供“已答 N／总数”的无障碍说明。点击后圆形入口隐藏，浮层展开至内容区的 65%。浮层顶部同一行放置小题序号、细拖拽杆和关闭按钮，拖拽热区至少 48px，移动超过 8px 后跟手调高，范围为内容区 35%～90%，松手保留高度；取消手势恢复起始高度，点按把手在 65% 和 90% 间切换，右上角关闭后恢复圆形入口。正文滚动保持面板高度。当前页面按材料修订记忆原文位置、浮层开合和高度，同材料切题保留这些状态，小题正文归零；切题、隐藏页面、窗口变化结束旧手势。键盘出现时优先显示输入内容，关闭后恢复。阅读题结构独立于四模块排序和比例，底部工具栏固定保留纠错、收藏、答题卡、标记，小题切换使用页面底部上一题／下一题，末题使用正式交卷或返回行为。

普通题默认采用顺序模式，题号计时栏、题干、作答区按保存顺序自然排列并共同滚动，顶部导航和底部翻题按钮固定。工具栏排在保存顺序的最后时，固定于翻题按钮上方；排在其他位置时随内容按用户顺序显示。普通长题向下滚动查看选项。自定义模式使用固定题干／作答分区，题干占比 30%～70%、步长 5%，短选项靠底、长内容在分区内滚动，详解随对应内容区滚动。布局编辑中两种模式均可拖动四模块排序，右侧依次为模式按钮、比例杆、预览按钮；模式直接切换，顺序模式禁用比例控件并保留自定义比例。预览使用未保存草稿，隐藏模式、比例及排序控件；原位的预览按钮切换为“返回编辑”，示例含四个选项及模拟作答详解。模式、顺序和比例一次保存，失败保留草稿；恢复默认设为顺序模式、常规模块顺序和备用比例 50%／50%，保存后生效。旧偏好缺少 `layoutMode` 时使用顺序模式，保留已存模块顺序和有效比例。

客观得分为答对题数除以客观总题数，未答占分母；正确率按答对除以客观已答计算。主观题独立统计，不进入客观得分和正确率。全部主观题的得分为空。主观待复习按最后一次明确自评更新。

累计作答题次按所有正式提交的有效作答累计；同题重复作答重复计数。已练不同题数按题目 ID 去重，阅读材料本身不计题。历史指标独立于分类和当前公开目录，客观已答为零时正确率为空，主观自评单独显示。

判题、整卷批改和成绩生成由小程序完成。云端保存客户端的逐题结果与汇总，校验身份、题目修订和数据结构。重复交卷只保存一份结果。每场练习固定创建时的题目、答案、解析和阅读材料；新练习使用云端当前内容，历史成绩保留。回看发现题目更新时提供新版内容入口，新版题目与答案配套展示。

错题本点开题目详情后，直接展示当前版本的题目、正确答案和“试题详解”。阅读材料、小题、紧凑选项、答案摘要及详解在同一区域连续滚动；选择题答案摘要显示选项字母，判断题显示正确／错误，填空与简答保留完整参考内容。单题回看只显示本次入口实际持有的作答；练习上下文中的作答和参考资料保持该场次修订及揭晓规则。

即时反馈确认客观题后，答错立即进入错题本，答对更新已有错题的掌握状态；草稿不收录。非即时模式在交卷后更新错题本。已确认条目按 ID 去重，同步重试和交卷沿用同一条记录。收藏在所有模式下始终立即保存到收藏本。正式成绩、累计答题量和练习次数在交卷后统计；主观题仍由交卷后的明确自评决定是否待复习。结果页可按指定题目重练当前错题。

## 本机恢复与同步

进行中的练习固定绑定创建设备。同一设备支持退出、重启和断网续答；已下载的快照与草稿持久保存。标准答案、参考答案、解析和判题规则使用微信加密存储，判题或展示时读取对应资料。完整快照及附件落盘后才能开始答题。

交卷时小程序确认非空草稿、完成批改并可靠保存最终结果和交卷意图，随后立即显示成绩与解析。练习记录显示“进行中／已完成”，正常答题安静保存。网络暂不可用时需要提示则显示“已保存在本机，可继续练习”；本地保存失败必须提示并保留作答。后台合并变化，普通进度约六十秒错峰上传，交卷优先。云端保存完成后，同账号其他设备可查看。未收到完成回执的内容保留本地。

游客共用本机累计两次试答额度。完整快照和附件成功落盘后才扣次；恢复、回看和账号切换不增加次数。累计计数独立于快照，首次建立时从零开始。游客试答独立保存在本机，不进入账号成绩与同步队列。

设置页顶部提供默认答题配置入口，正文分为“即时答题设置”“通用设置”和“题目显示”。即时答题设置包含答对后自动下一题、左滑时先确认答案，适用条件分别写在单项说明中。“左右手势切题”默认开启；关闭时禁用左滑确认开关并保留其值，重新开启后恢复。左滑确认默认关闭，多选和填空在即时反馈下可先确认答案，关闭时保存草稿并切题。通用设置包含“答题卡选项显示外框”和答题时振动；外框默认关闭，开启后普通题、阅读小题和自定义布局预览的所有选项显示浅色描边。

题目配置及预设编辑 BottomSheet 中，练习模式提供“反馈时机”和“出题顺序”两组选项按钮，沿用答题模式的蓝色选中、浅灰未选中样式。反馈时机可选“即时反馈／交卷后反馈”，出题顺序可选“顺序出题／随机出题”，默认即时反馈、顺序出题。选择交卷后反馈时，交卷统一揭晓对错、答案和解析；模拟考固定交卷后反馈并随机出题，背题直接查看答案并按题库顺序展示。手动修改只影响本次配置，保存为预设后可复用。首页快速开练、章节、错题与收藏练习使用默认预设，保留各自题目来源。

详解按模型的揭晓条件直接显示。旧 autoOpenAnalysis 偏好和练习快照保留读取兼容，设置页移除对应开关；旧下拉解析实现作为停用备选保留。答对自动下一题默认关闭；开启后，确认答对的客观题等待 0.8 秒切题，期间保持当前阅读位置，手动操作取消跳题；回看已答题不重新计时跳题。简答题的参考答案仍在交卷后展示。

字号为小、标准、大、特大、超大五档，对应 14／18／20／22／24px，默认标准。五段滑杆位于固定 160px 高的预览上方，档位文字可点击；拖动实时预览、松手保存，失败恢复已保存值并提示。字号返回答题页后立即生效。恢复默认只恢复答题习惯，保留预设、默认预设、布局和倒计时。每次练习固定模式、反馈方式、题序、题量、时长及自动跳题、手势切题、左滑确认选项；修改或删除预设不改变已有练习。上述配置保存在本机，布局示例不产生学习记录或消耗试答额度。

考试倒计时支持多场考试，以卡片列表展示。新增表单位于当前页顶部，编辑在原卡片内展开，删除须确认。首页优先展示日期最近的未结束考试；全部结束时展示最近结束的一场。恢复答题默认设置保留全部倒计时。

## 内容管理

所有管理员使用独立超级管理员账号；系统至少保留一个启用账号。题库维护者表示工作分工。内容导入采用[题库导入协议](question-bank-import.md)，每批最多 3000 道作答题、8 MiB UTF-8 请求体，整批事务提交。

公告支持指定受众、定时发布、置顶和交流群二维码。首页倒计时下显示首条可见置顶公告；喇叭打开首条公告正文；顶部横向胶囊标签展示标题，正文从日期开始，点击切换正文，滑动分页查看历史公告。首页答题卡片下提供带右箭头的交流群入口，点击预览二维码。仅在状态和图片校验通过后展示；不可用时隐藏卡片，返回首页或下拉刷新重新获取，二维码到期时重新核对状态。群码有效期由管理端维护，过期后停止提供图片。反馈保留学生提交时的题目快照，结束处理前填写回复。

题目纠错和缺课需求共享未读提醒。管理员新增或修改非空回复、变更已有回复的处理状态后，底栏“我的”、反馈入口和对应分类标签显示红点；原样保存保持原版本和处理时间。学生列表按处理更新时间倒序，回复实际进入前台页面可视区域后逐条确认已读，未查看的分类和屏幕外记录继续保留提醒。已读状态按账号保存到服务端，确认旧版本只清除已看到的内容，新版本仍为未读，确认操作保持处理时间和排序。进入小程序、返回或切换主页面、下拉刷新时重新检查摘要，其他设备在下次刷新时同步。查询或确认失败时保留已知状态，下次进入或刷新时重试。

## 内容检测与账号注销

用户提交的昵称、头像、反馈及缺课需求通过微信官方内容安全检查后保存。小程序每次取得新的微信登录凭证建立短期检测上下文，纯邮箱用户可使用，检测身份不自动绑定为登录身份。文本、附件和内容版本共同校验；未通过、需复核、异常或超时保留原内容。管理员在管理端按权限编辑、导入和发布内容，由后端校验输入、业务版本及幂等请求，并记录审计。

个人资料页提供账号注销入口；注销须复核当前登录身份并明确确认。事务撤销会话、释放绑定、删除私人学习数据、同步命令、邮件和检测任务；去标识化审计保留操作事实。当前设备清理该账号的数据，保留其他账号、分类筛选和本机偏好。注销证明只在内存持有，同一证明和幂等键可重试完成回执。

四个主页面下拉刷新共用“正在刷新”和完成时间反馈，失败时提示下拉重试；重复下拉合并在途请求，离开页面清理提示。题库的两列滚动区域均支持下拉，刷新保留当前科目和分类。首页刷新同时重新获取群码。

公告正文展示后按账号与公告版本保存本机已读状态；存在未读公告时首页喇叭提示，全部已读后静止，新公告或公告更新重新提示。
