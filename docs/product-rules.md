# 产品规则

题小搭面向课程复习，包含微信小程序、内容管理端和后端，应用版本为 `1.0.0`。

## 目录与访问

学院、专业、年级用于题库分类。筛选保存在当前设备，默认全部；重置按钮清空筛选，再次点击恢复上次条件。切换学院清除不适用专业。分类为空表示通用题库；同一分类记录内共同匹配已选条件，未限定维度视为通用，多条记录取并集。

游客与不同账号使用相同的公开条件：课程启用、题库启用且发布、存在有效作答题目；阅读小题同时要求材料启用。分类只影响目录和搜索，公开内容可按 ID 直接打开。停用、下架和归档保留已有练习的固定修订、成绩、反馈及历史引用。章节只允许删除空章节。

邮箱验证码或微信验证成功直接登录，首次使用自动创建账号。邮箱、微信绑定冲突明确拒绝；更换邮箱验证新旧邮箱并撤销旧会话。资料保留昵称、头像和账号绑定。管理员使用独立密码登录。测试账号规则见[测试账号管理](test-accounts.md)。

邮箱或微信首次建号时，后端从六款官方默认头像中等概率随机分配一款并保存；再次登录读取已保存头像，已有账号保留当前头像。个人资料页通过微信原生头像选择器更换头像，经内容检查后保存。

小程序底栏包含首页、题库、复盘、我的四个等宽入口。首页学习入口下方提供答题卡片：当前设备有未完成练习时继续答题，否则可通过两列联动选择最近练过的科目和题库，创建新答题；没有练习记录时进入题库。新答题采用设置页指定的默认预设，练习顺序和解析显示沿用长期偏好。题库保留左侧科目、右侧统计与章节列表；学院、专业、年级三个筛选位于题库搜索框下方。复盘优先显示错题、收藏与重练。

## 练习与结果

支持单选、多选、判断、填空、简答和阅读题组；阅读题量按小题计算。普通、随机和模拟练习按完整题组选择；错题和收藏可选择小题并携带材料。同科目可以联合多个题库，每次最多 1000 道作答题。

题库章节正文和搜索结果使用全局默认预设直接开练；尾部调节图标打开本次答题配置。章节题数紧跟标题，以空格分隔并显示为灰色。常规练习中，蓝色整科卡片点击打开配置，卡片尾部显示“整科练习”。预设在“答题偏好 → 点击章节时使用的配置”中管理，可命名、新增、编辑、删除及指定默认；默认预设先更换再删除。初始为“日常练习”：练习模式、20 题、不限时。预设只保存模式、题量和时长，选择题库、章节、错题范围不进入预设。配置弹层中独立一行选择预设及保存当前配置，开始答题按钮单独占满一行。手动修改后标记自定义；点击“保存为预设”直接新增并选中，名称按“模式 - 题量档位 - 时长”生成，例如“练习 - 全部 - 不限时”。题量按当前选项从少到多命名为 1档、2档、3档等，最高项为“全部”；列表仍展示实际题量摘要，名称可在预设列表编辑。按模式、请求题量和时长判断配置是否重复；快捷保存遇到已有配置时直接选中已有项并保留名称，预设列表新增或修改时拒绝与其他预设配置重复。保留全局默认项，保存失败保留当前配置。预设保存请求题量，例如请求 20 题、当前仅有 8 题时仍保存 20；主动选择“全部”才保存全部。

题量按当前范围的实际题数生成档位，最高档为“全部”；不足指定题量时使用全部题目。超过单次 1000 题时禁止选择全部并提示缩小范围。普通和模拟练习完整保留阅读题组，实际题量调整时明确说明。答题时间直接选择不限时、10、20、35 分钟或自定义 1～1440 整数分钟，背题不限时。模拟考支持不限时，交卷后统一揭晓；背题直接展示答案和解析。

首页模拟考先进入题库选择章节。左侧科目用于切换右侧章节列表；点击章节、搜索结果或顶部整科卡片，以所选范围的全部题目和固定 45 分钟直接开考，不弹出配置，也不修改默认预设。整科卡片覆盖当前科目的全部题库；章节和搜索结果隐藏配置图标。退出选择、离开题库 Tab 或成功开考结束选择状态，切到后台保留状态。单次题量超过 1000 题时保留现有上限并提示缩小范围，不截取部分题目冒充全部。

创建时固定题目、顺序、内容修订、反馈模式和计时配置。即时反馈确认客观作答后，答案解析 TopSheet 从内容区顶部自动展开；面板与把手同步移动，松手保留当前位置，只有距顶部栏 32px 内才吸附收起。把手支持拖动与点按；未作答及待确认草稿隐藏入口。统一反馈在交卷后显示，背题在题干阅读区直接展示答案与解析。题干与作答按本机比例固定分区，选项在作答区内靠底排列，长内容独立滚动。填空逐空匹配，全部空位正确才判整题正确。已作答的简答题交卷后显示“这道题掌握了吗？”，可选择“已掌握”或“还需复习”，也可不选。答题卡在答题过程中始终可用。

客观得分为答对题数除以客观总题数，未答占分母；正确率按答对除以客观已答计算。主观题独立统计，不进入客观得分和正确率。全部主观题的得分为空。主观待复习按最后一次明确自评更新。

累计作答题次按所有正式提交的有效作答累计；同题重复作答重复计数。已练不同题数按题目 ID 去重，阅读材料本身不计题。历史指标独立于分类和当前公开目录，客观已答为零时正确率为空，主观自评单独显示。

正式成绩由后端重算。重复交卷只生成一份结果，内容后续修改不改变已发放练习。

“自动收录错题”以交卷时的答题偏好为准。关闭后不再收录新错题，已有错题继续随复习结果更新。结果页可按指定题目重练当前错题，不要求这些题目已收录到错题本。客观成绩、正确率和答题量照常统计；主观题仍由明确自评决定是否待复习。

## 本机恢复与同步

进行中的正式练习固定绑定创建设备。同一设备支持退出、重启和断网续答；已下载的快照与草稿持久保存，联网后通过异步命令同步。已提交记录可在同账号其他设备查看。

游客共用本机累计两次试答额度。完整快照和附件成功落盘后才扣次；恢复、回看和账号切换不增加次数。累计计数独立于快照，首次建立时从零开始，保留已有试答内容。游客试答独立保存在本机，不进入正式成绩与同步队列。

设置页提供默认预设管理、自动跳题、错题收录、振动、练习随机出题、答完即显示解析、文字大小及左滑处理未确认答案。“左右手势切题”使用开关，默认开启；关闭时禁用“左滑时先确认答案”，保留其已保存值，重新开启后恢复可操作。“左滑时先确认答案”使用开关，默认关闭并保存草稿切题，开启后先确认答案；该选择随练习在本机快照中固定。随机出题和解析使用单行开关：关闭随机出题时按题库顺序，关闭即时解析时交卷后查看；简答题解析始终交卷后查看。文字大小先展示预览，再提供小／标准／大选项。预设以卡片列表展示，新增按钮固定在底部；新增和编辑打开可滚动的 BottomSheet，取消或关闭不保存，保存失败保留草稿。恢复默认只恢复长期习惯，保留预设、默认预设、布局和倒计时。顺序和解析、自动跳题只影响练习；解析延后不影响即时显示对错和正确答案。首页快速开练、错题和收藏练习使用默认预设，保留各自题目来源。每次练习在本机快照中固定模式、题量、时长及解析、自动跳题、手势切题及左滑处理未确认答案的选项，修改或删除预设不改变已有练习；旧快照首次恢复时补存当前偏好。上述配置和布局、倒计时均保存在本机。布局编辑复用实际答题模板，示例不产生学习记录或消耗试答额度。

考试倒计时支持多场考试，以卡片列表展示。新增表单位于当前页顶部，编辑在原卡片内展开，删除须确认。首页优先展示日期最近的未结束考试；全部结束时展示最近结束的一场。旧版单场倒计时读取时自动转换，恢复答题默认设置保留全部倒计时。

## 内容管理

所有管理员使用独立超级管理员账号；系统至少保留一个启用账号。题库维护者表示工作分工。内容导入采用[题库导入协议](question-bank-import.md)，每批最多 3000 道作答题、8 MiB UTF-8 请求体，整批事务提交。

公告支持指定受众、定时发布、置顶和交流群二维码。首页倒计时下显示首条可见置顶公告；喇叭打开公告列表，点击进入详情并可返回列表。首页答题卡片下提供带右箭头的交流群入口，点击预览二维码。仅在状态和图片校验通过后展示；不可用时隐藏卡片，返回首页或下拉刷新重新获取，二维码到期时重新核对状态。群码有效期由管理端维护，过期后停止提供图片。反馈保留学生提交时的题目快照，结束处理前填写回复。

## 内容检测与账号注销

用户提交的昵称、头像、反馈及缺课需求通过微信官方内容安全检查后保存。小程序每次取得新的微信登录凭证建立短期检测上下文，纯邮箱用户可使用，检测身份不自动绑定为登录身份。文本、附件和内容版本共同校验；未通过、需复核、异常或超时保留原内容。管理员在管理端按权限编辑、导入和发布内容，由后端校验输入、业务版本及幂等请求，并记录审计。

个人资料页提供账号注销入口；注销须复核当前登录身份并明确确认。事务撤销会话、释放绑定、删除私人学习数据、同步命令、邮件和检测任务；去标识化审计保留操作事实。当前设备清理该账号的数据，保留其他账号、分类筛选和本机偏好。注销证明只在内存持有，同一证明和幂等键可重试完成回执。

四个主页面下拉刷新共用“正在刷新”和完成时间反馈，失败时提示下拉重试；重复下拉合并在途请求，离开页面清理提示。题库的两列滚动区域均支持下拉，刷新保留当前科目和分类。首页刷新同时重新获取群码。
