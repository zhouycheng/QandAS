## 改名涉及的行为

| 范围 | 典型位置或标识 | 修改时的联动 |
| --- | --- | --- |
| 用户可见名称 | 小程序首页／登录／关于、分享标题、用户协议、管理端标题与登录、邮件和 Excel 文件名 | 替换文案、标题和导出名称，核对截图与分享落地 |
| 包与构建身份 | `package.json`、Maven `groupId/artifactId`、`qanda.backend`、Mapper XML 类型名、JAR 名称 | 同步源目录、包声明、引用、构建及启动脚本；完整编译和合同再生成 |
| 本机数据 | `qandaAuth`、练习快照、草稿、同步队列、分类与偏好键 | 若修改键名，需要读旧键、迁移并验证恢复，避免账号及离线数据丢失 |
| 部署与数据资源 | Compose 项目／容器／卷、数据库及账号、systemd、sudoers、备份、Prometheus 指标 | 核实现有资源与依赖；已有数据库、卷和备份需保持可恢复 |
| 测试账号命名空间 | `QANDATEST001@qanda.mail` 及匹配规则 | 这是当前明确约定的测试身份；是否随品牌一起改需单独确定，并同步保留／禁用规则与管理凭据 |
| 生成文件 | OpenAPI、Postman、包锁文件 | 修改生成源后重新生成和校验，保持调用方一致 |
| 外部设置 | Git 仓库名／remote、域名、证书、小程序名称、邮件发件配置、CI 配置 | 当前统计只覆盖本仓库中的引用；外部系统需分别核对 |

## 扫描边界

- Git 历史、依赖目录、编译产物、运行日志、临时预览和本机缓存依照忽略规则排除；这些产物应在改名后重建。
- 二进制文件参与路径统计，其图片文字、图标内嵌名称及其他编码内容未进行 OCR 或视觉核对。
- 仓库外私有配置、实际服务器数据、平台登记及其他外部持久状态未纳入扫描。
- 本清单保留改名前的审查依据；当前产品名称见“产品名称”一节，外部平台及技术标识需按各自同步流程核对。
