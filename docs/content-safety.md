# 内容安全接入

应用使用微信官方 `msg_sec_check` v2、`media_check_async` 和稳定访问凭据接口。用户提交的内容检测明确通过后才允许保存。违规、需复核、异常和超时均保留原内容，用户可修改后重试。

## 业务流程

小程序提交昵称、头像或反馈前取得新的 `wx.login` code，创建绑定当前业务会话、有效期五分钟的检测上下文。检测使用的微信身份独立于登录绑定，邮箱用户可以直接使用。待保存内容的摘要和业务版本绑定检测请求，保存事务再次核验并消费通过结果。

管理员通过管理端编辑、导入和发布内容，由后端校验管理员权限、输入、业务版本及幂等请求，并记录操作审计。

头像及待检测图片保存在私有检测表。媒体检查通过专用、有时效且不可缓存的地址取件；回调签名、AES 密文、AppID、时间窗口和事件类型均校验。任务根据 trace ID 去重，旧任务不能保存到新内容版本。原头像在媒体检查通过并提交保存后替换。上传到题库的原始附件保持私有，只有已经检测的题目引用或发布快照才能公开提供。

用户内容检测网络请求在保存事务外执行，保存事务核验当前会话、业务版本和内容摘要。题库发布继续校验有效题目、答案、解析、附件和分类等业务条件。

worker 读取持久化请求，处理文本和媒体提交；回调可重复到达。请求三十分钟后到期，定时清理候选内容和媒体数据。服务异常可在原编辑界面重试。注销清除该账号的上下文和任务；迟到 worker 或回调不能重新建立私人资源。

运行中的检测请求由 worker 令牌与心跳共同标记；心跳超过六十秒未更新且请求仍有效时，清理任务将其恢复为待检查状态。旧 worker 保存结果时仍须匹配原令牌，避免恢复后的迟到结果覆盖新任务。

## 私有配置

| 字段 | 用途 |
| --- | --- |
| `BACKEND_WECHAT_APP_ID` / `BACKEND_WECHAT_APP_SECRET` | 当前小程序身份交换和稳定访问凭据 |
| `BACKEND_CONTENT_SAFETY_PROVIDER` | 默认 `official`；`local` 仅允许显式本机开发／测试运行 |
| `BACKEND_CONTENT_SAFETY_PUBLIC_BASE_URL` | 微信可以取件的 HTTPS 源站，无查询参数及用户信息 |
| `BACKEND_WECHAT_CALLBACK_TOKEN` | 微信公众平台消息推送校验 Token |
| `BACKEND_WECHAT_CALLBACK_AES_KEY` | 平台 EncodingAESKey，43 字符 |

平台登记回调路径为 `/api/v1/content-safety/wechat-callback`，启用安全加密及 JSON 事件格式。先验证 GET 握手，再验证真实媒体异步回调。专用取件路径为 `/api/v1/content-safety/media/{id}`，参数由服务临时生成。仓库提供的两层网关对这些路径关闭访问日志；其他入口如 CDN 也须采用同样的敏感参数处理。

密钥保存在仓库外权限为 `600` 的私有配置。自动测试使用隔离数据库、本地提供端和签名加解密样例；真实平台权限、邮箱账号的实际检测、媒体公网取件及回调分别记录实测结论。

## 平台隐私与发布核对

小程序登录前及我的页均提供可打开的协议和隐私正文。平台隐私指引需按实际行为登记邮箱、微信身份、头像、学习记录、反馈及微信内容检测用途。发布前核实实际主体、服务类目、备案、请求及文件域名、内容版权和审核体验。平台配置完成情况以公众平台和真机证据为准。
