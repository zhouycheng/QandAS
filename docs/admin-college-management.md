# 科目显示范围

学院下维护专业，年级使用大一、大二、大三、大四、已毕业五档。目录提供科目筛选选项，用户可在本机自由筛选。

管理端沿用左侧学院目录和右侧专业工作区，通过分页接口读取、通过原有弹窗新增和编辑。课程显示范围支持多条分类条件，每条可限定学院、专业和年级；专业所属学院由目录关系解析。范围留空表示通用科目。升级时已有科目统一设为通用。

目录停用后，客户端清理失效选择并提示。分类只改变列表和搜索匹配，按 ID 打开公开内容、历史练习和统计均独立处理。公告指定用户投放继续使用独立的接收名单。

后端公开条件由 `bank_visible`、分类条件由 `subject_matches_category` 统一表达。目录、列表与搜索采用相同条件。
