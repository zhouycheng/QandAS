# 题库分类目录

学院下维护专业，年级使用大一、大二、大三、大四、已毕业五档。目录描述题库分类，用户可在本机自由筛选。

管理端沿用左侧学院目录和右侧专业工作区，通过分页接口读取、通过原有弹窗新增和编辑。题库设置使用多条分类条件，每条可限定学院、专业和年级；专业所属学院由目录关系解析。空分类表示通用题库。

目录停用后，客户端清理失效选择并提示。分类只改变列表和搜索匹配，按 ID 打开公开内容、历史练习和统计均独立处理。公告指定用户投放继续使用独立的接收名单。

后端公开条件由 `bank_visible`、分类条件由 `bank_matches_category` 统一表达。目录、列表与搜索采用相同条件，管理端预览遵循相同的交集、并集和通用维度规则。
