# 性能检查

以下为相同本地用例及构建命令下的观察，属于数据量和产物检查。真机耗时与服务容量另行测量。

## 小程序视图更新

构造相同结构的单选题，点击首题选项，比较完整展示数据与实际 `setData` 补丁：

| 题量 | 完整数据 | 字段补丁 |
| --- | ---: | ---: |
| 20 | 6088 B | 706 B |
| 100 | 20731 B | 706 B |
| 1000 | 188135 B | 707 B |

补丁更新后的完整页面数据与原展示数据逐项比较相等。检查入口为 `apps/miniapp/tests/result-review.check.js`。作答时 Page 发送变化字段及数组项；计时只生成计时字段，保留输入焦点与页面命令行为。

## 管理端构建

同一依赖环境执行生产构建，拆分业务页面并移除运行时演示依赖后，最大 JavaScript 块由 785.57 kB 降至 478.69 kB，对应 gzip 由 253.34 kB 降至 142.93 kB。业务页面保留按需加载。

## 后端及运行时

题目修订、选项、附件和阅读材料采用批量读取；跨设备接力的周期请求已退出运行路径。异步同步、幂等、重试、死信恢复和监控继续提供可靠性保障。

隔离 PostgreSQL 中，用相同的 1000 道单选题比较同一题目读取器的逐题调用与批量调用。两种方式返回的题目、选项和答案逐项相等：

| 题量 | 逐题调用 SQL 次数 | 批量调用 SQL 次数 |
| --- | ---: | ---: |
| 20 | 80 | 4 |
| 100 | 400 | 4 |
| 1000 | 4000 | 4 |

检查入口为 `QuestionBatchPostgresTest`，日志中的 `QUESTION_BATCH_EVIDENCE` 同时记录耗时。这组数据衡量题目读取，不包含整次练习创建的写入、锁和权限检查。创建练习的指定题目范围校验及阅读材料修订也采用批量查询。

微信实际上传包体、真机交互、整个 HTTP 流程耗时和并发容量需在对应环境记录。源文件删减量不能代替这些指标。删除文档、无调用接口以及拆分文件主要减少维护成本。
