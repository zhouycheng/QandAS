# 用户协议与隐私政策

用户协议与隐私政策的正文统一维护在 [legal-content.js](../apps/miniapp/miniprogram/utils/legal-content.js)，登录页的独立协议页面和“我的”页弹层共用同一份内容，均支持选择文本。更新日期为 2026 年 11 月 5 日，共同运营者为周耀程、岳申奥、庞江锋、蒋嘉乐，统一服务与个人信息保护联系邮箱为 417684818@qq.com。

当前为待发布稿。业务条款已按当前代码补齐；存储地区、接收方及记录留存等实际运营信息仍需补充。正文中的 `【待填写】` 项补齐、对应安排落实后，再确定生效日期和正式版本。

## 正文范围

用户协议覆盖服务及学习结果、登录身份、离线数据、使用规范、知识产权、反馈内容授权、第三方服务、服务调整、责任、申诉、注销、未成年人及争议解决。

隐私政策按实际功能列出信息类别、目的、触发时机及拒绝影响，区分本机存储、服务器处理、第三方提供、在线删除和备份处理，说明查阅、更正、复制、转移、撤回同意及注销的途径。

## 代码依据

| 事项 | 当前行为及维护入口 |
| --- | --- |
| 邮箱与微信登录 | `IdentityService.kt`、`WechatExchange.kt`、`auth-repository.js`：首次验证建号；微信返回 OpenID 及可选 UnionID；本机随机设备标识与登录状态持久化 |
| 验证与会话 | `ChallengeService.kt`、`IdentityService.kt`：验证码有效期 10 分钟，普通会话最长 30 天；有效期不代表验证、投递记录的删除期限 |
| 资料与内容安全 | `ContentSafety.kt`、`WechatContentChecks.kt`：昵称、头像、反馈及课程需求经微信检查；邮箱用户也建立微信检测上下文，检测身份不自动绑定登录 |
| 检测材料清理 | `ContentSafety.kt`：上下文 5 分钟、请求 30 分钟失效；清理任务移除过期正文和媒体，过期请求及回调记录一天后进入清理范围 |
| 邮件接收方 | `TencentSesTransport.kt`：腾讯云 SES 接收邮箱、验证码及模板数据；代码允许广州和香港地区，实际配置尚未核实 |
| 目录筛选 | `catalog-filters.js`、`remote-data-repository.js`：筛选在本机保存，查询时会发送学院、专业和年级参数；不能宣称筛选信息完全不上网 |
| 学习与本机数据 | `online-practice.js`、`trial-practice.js`、`activity-heartbeat.js`：正式练习按账号同步，游客试答保存在本机；登录后前台发送活跃状态 |
| 反馈及管理 | `OperationsService.kt` 和管理端账号功能：反馈与账号关联，管理员处理回复；管理端可导入、导出账号资料 |
| 注销 | `AccountDeletion.kt`、`account-deletion-repository.js`：删除在线私人数据并清理当前设备对应账号；保留本机偏好、游客数据和其他账号数据；审计去除直接账号关联 |
| 备份 | [部署说明](deployment.md)：备份包含数据库和附件，现有脚本不会自动删除历史备份；注销在线记录不能证明备份已删除 |

Kotlin 文件位于 `apps/api/src/main/kotlin/qanda/backend/` 对应模块，JavaScript 文件位于 `apps/miniapp/miniprogram/repositories/`。该表记录代码依据，不代表已核实生产配置、供应商履约或真机行为。

## 发布前需要落实的事项

| 事项 | 需要补充或核实的内容 |
| --- | --- |
| 共同运营 | 四位共同运营者应按实际共同决定处理目的和方式的关系明确各自职责，并核对微信登记主体。内部约定不限制用户向任一共同处理者行使权利 |
| 存储与接收方 | 业务数据库、附件、备份的国家或地区；实际基础设施服务商名称、联系方式及数据范围；微信服务的实际合同主体及联系渠道 |
| 邮件地区 | 核实实际启用的 SES 地区、合同及数据处理安排；涉及境外处理时补齐相应告知和法定程序 |
| 保存期限 | 为验证与邮件投递、反馈、访问日志、审计、活跃记录确定期限或明确确定方法，落实到期清理。验证码失效不能代替材料清理 |
| 备份删除 | 确定保留期限、删除流程、访问限制，以及恢复备份后重新执行既有删除请求的安排 |
| 权利请求 | 确认联系邮箱有人受理，落实身份核验、复制、删除、撤回同意、转移及答复流程；目前只有部分操作提供自助页面 |
| 同意与更新 | 当前登录框默认不勾选；邮箱验证码可在勾选前发送。核实首次信息处理前的告知、内容检测场景提示、需要时的单独同意及版本更新告知。现有代码未提供协议版本同意记录与强制重新确认机制 |
| 未成年人 | 现有代码未实现儿童年龄核验、监护人同意或专门处理规则；如向不满十四周岁用户提供涉及个人信息的服务，需要补齐相应安排 |
| 微信平台与展示 | 按实际处理行为填写平台隐私指引；在开发者工具及真机检查长文滚动、正文选择、协议入口和必要授权提示 |
| 生效 | 由运营者确定生效日期，替换所有待填写项，并保存正式发布版本 |

## 公开依据

- [《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)：告知处理者身份与联系方式、保存期限、权利途径，以及委托处理、单独同意和未成年人保护要求。
- [《网络数据安全管理条例》](https://xzfg.moj.gov.cn/front/law/detail?LawID=1734)：第二十一至二十三条关于处理规则、信息清单和权利行使的要求。
- [《民法典》](https://www.court.gov.cn/zixun/xiangqing/233181.html)：第四百九十六、四百九十七条关于格式条款提示及效力的要求。
- [腾讯云隐私保护声明](https://cloud.tencent.com/document/product/301/11470)：核对腾讯云运营主体和联系渠道；题小搭对自身用户的信息处理仍由本政策说明。
