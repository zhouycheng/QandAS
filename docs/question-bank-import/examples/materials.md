## 3. 知识讲义

RAM 通常是易失性存储器，需要持续供电来保持其中的信息；断电后信息通常会丢失。

中央处理器的英文名称是 Central Processing Unit，缩写为 CPU。

数据备份在独立位置或版本中保存数据副本，可用于故障或误删后的恢复，也可保留历史版本以便恢复到此前状态。普通同步是否保留历史版本取决于同步系统的设置。
