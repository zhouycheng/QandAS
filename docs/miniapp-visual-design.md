# 小程序视觉规范

题小搭使用蓝白配色和系统无衬线字体。视觉变量维护在小程序的 `utils/design-tokens.js`，构建时生成 WXSS；页面、隔离组件、浮层及图表共用该来源。

判断题选项使用 A／B 标识，正文分别为“正确”“错误”；作答结果在确认后的反馈区域显示。

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 底栏、时间、题数 | 11 / 16px | 400 |
| 描述、筛选、辅助操作 | 12 / 18px | 400 |
| 正文、字段名、按钮、模块标题 | 14 / 22px | 正文 400，操作 500，标题 600 |
| 四个主导航、二级页导航、弹层标题 | 16 / 24px | 600 |
| 首页问候、关于页应用名 | 18 / 26px | 600 |
| 登录品牌名、核心数字 | 24 / 32px | 600 |

题目小、标准、大三档统一使用 12 / 14 / 18px、1.65 倍行高，覆盖题干、选项、材料、答案、解析和结果回顾。代码继承阅读字号并保留横向滚动。

品牌色为 `#2563EB`，正文为 `#1F2937`，辅助文字为 `#667085`。蓝色表示可操作和选中，绿、橙、红分别表示成功、提醒和错误；状态同时使用文字或图形表达。首页四个学习入口使用纯色蓝底和白色图形。

标准按钮使用共享 `q-button` 样式，填满所在容器；同行操作由父容器分配空间。文字按钮和紧凑按钮按内容确定宽度，验证码按钮宽 88px。按钮保持至少 44px 点击高度。相邻纵向操作、说明与主要操作之间留 12px，操作组前留 16px。

页面间距使用 4 / 8 / 12 / 16 / 24px 基准并按现有 rpx 布局换算；普通卡片和按钮圆角 12px，标签圆角 8px，弹层圆角 20px。底栏、圆形头像保留各自形状。

个人资料、答题偏好、自定义布局、反馈、考试倒计时和关于页共用 `styles/settings-detail.wxss`。左右边距为 32rpx，字段名为 14px 常规字重，说明及状态为 12px；列表行至少 48px 高，使用统一细分隔线和浅灰输入区。共享页面基准同时用于滚动内容和底部操作的左右对齐。

同一项的标题与说明间距为 2px。行分隔线由共享伪元素绘制为 0.5px 细线，每行仅绘制底部一条。

自定义布局使用单一通用模板，包含题目信息、题干、作答区和工具栏。按住模块拖动调整顺序，移动超过 8px 后开始排序；底部提供“恢复默认”和“保存”。右侧固定悬浮竖向比例滑杆，上下分别显示题干与作答百分比，支持上下拖动和加减；题干范围 30%～70%，步长 5%，默认各占 50%。题目信息与工具栏保持固定高度。预览按当前屏幕实际可用高度铺满，扣除导航、底部操作及固定模块、内外边距后使用与答题页相同的分配规则。选项组始终在作答区内靠底排列，长内容在区域内滚动。比例与排序只更新草稿，统一保存；当前值与已保存布局相同时禁用保存，失败保留草稿。

答题导航栏显示课程名称。内容区信息行依次显示题号、模式标签、题型标签及用时，两个标签共用浅灰块样式。

即时反馈确认当前客观题答案后，从答题内容区顶部自动展开答案解析 TopSheet，占内容区约 70%，正文独立滚动。把手连接面板下沿，收起、拖动及展开共用一个节点，透明点击区至少 44px 高；面板与把手跟随手指同步移动。上下拖动后松手停在当前位置，只有距顶部边缘 32px 内才吸附收起；点按把手可切换展开状态。未作答、待确认草稿和统一反馈过程隐藏入口。解析按既有偏好显示，背题模式在题干阅读区直接展示答案与解析。切题重置解析滚动位置，进入未答题或离开页面时收起；底部导航持续可用。

阅读题顶部使用共享 `pra-meta` 信息行样式，标签区可换行，题号、计时和答题卡保持可见。原文与小题各自滚动，小题采用连续题干与作答结构。底部把手区高 56px，32×4px 指示条居中，下方为浅灰进度文字及拖动提示。首次进入材料默认半屏展开，半屏和近全屏分别占原文与面板共享区域约 50% 和 90%，底部导航持续可用。拖动在 WXS 视图层实时更新，松手采用 240ms 缓出吸附；慢拖选择最近档位，快速上下滑动选择相邻一档，触摸可接续尚未结束的动画。键盘显示时临时隐藏信息行、把手和小题标题，为输入保留空间；关闭后恢复原档位。

倒计时卡片使用 14px 名称、12px 日期和 24px 天数；今天与已结束状态使用 12px 标签。编辑表单在原卡片内展开，保存和取消后恢复卡片。首页保留时段封面，考试名称与剩余天数分两层展示，今天考试使用 16px 状态文字。

隔离组件在根节点应用 `portal-theme`，并导入共享样式；浮层在 `root-portal` 内建立主题边界。`style: v2` 的按钮默认宽度通过共享宽度规则覆盖，间距由所在页面管理。

账号安全、账号注销和内容确认共用设置页正文及表单基准，输入框文字为 14px，说明和验证反馈为 12px。验证码操作使用原生按钮并保留发送、加载和禁用状态。单个主要操作铺满容器，同行操作等宽分配，文字操作按内容宽度显示。

答题、结果回顾和题目详情的参考要点均将编号与正文作为同一段富文本渲染。题干、作答区、解析与工具栏通过 16px 基准间距分组；结果和详情底部保留安全区及操作空间。错题与收藏页复用二级导航，收藏管理独立放在操作行。

复盘图表只用 SVG 绘制图形；月份和日期标签使用原生 11px 文字，继承系统字体，不随图形宽度缩放。首尾标签向图形内侧对齐，月份中间标签居中，趋势末端的相邻日期按间距省略。

验收运行小程序构建和全部自检。运行时重点核对小屏换行、按钮间距、原生输入焦点、三档阅读字号、底栏与安全区。
