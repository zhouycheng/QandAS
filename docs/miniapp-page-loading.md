# 小程序页面加载与状态管理

核对日期：2026-11-05。应用与接口合同版本为 `1.0.0`。路由使用微信原生 API，共享资源使用 `mobx-miniprogram@6.12.3` 和 `mobx-miniprogram-bindings@7.0.1`。锁定版本及 npm 构建入口见 `apps/miniapp/package.json`。

## 页面加载

- App 在已登录且前台时立即上报心跳，每 60 秒一次；隐藏停止，失败不排队补传。心跳使用全局并发调度，不阻塞页面。
- 目录与搜索缓存加入学院、专业和年级筛选；本机筛选跨账号保留，私人进度与草稿按账号隔离。切换筛选和账号时拒收迟到响应。
- 题库开始练习、首页模拟考试和错题／收藏重练调用范围预览，实际题数和已选题目 ID 用于创建，阅读题组完整保留。
- 反馈页按题目纠错／课程需求分组，每次读取 20 条；提交后刷新当前列表。题目纠错携带当前修订，反馈结果从已有接口读取。
- 题目和材料附件按图片 ID 去重、缓存。完整快照创建或恢复时校验本机附件，缺失才下载；最多 4 个下载任务，共用全局并发。落盘失败保留原草稿并提示。
- 布局编辑复用答题模板，使用本机已作答示例，预览不产生 HTTP、学习记录或试答次数。

## 状态和请求规则

Repository 的 `resource-cache.js` 按用户、资源、查询参数和页码保存状态；`remote-data-repository.js` 负责请求及资源更新。ViewModel 将共享状态投影成展示字段，Page 使用官方绑定合并更新。练习答案、修订快照和待同步草稿继续由现有业务层持有。

| 资源 | 有效期 | 失效来源 |
| --- | --- | --- |
| 科目、题库、单题正文 | 5 分钟 | 目录刷新；练习结果更新相关进度 |
| 账号资料 | 5 分钟 | 修改资料、切换账号 |
| 学习概览、最近练习、统计、错题和收藏 | 30 秒 | 收藏、交卷、自评等学习写操作 |
| 公告各页 | 60 秒 | 主动刷新、切换账号 |
| 院校选项 | 24 小时 | 主动刷新、切换账号 |

- 同一个资源读取共用在途 Promise；有效缓存返回时零重复请求。读取失败保留已有数据，并提供区域错误提示。
- 失效后递增资源修订，旧请求即使随后返回也不能覆盖新数据。账号切换清空共享展示状态、取消旧读取，旧账号的迟到响应不能写入新账号。
- 本机学习概览和资料缓存按账号保存，格式版本为 1。练习草稿仍使用原用户的独立存储和格式规则。
- 全局业务并发上限 4，后台草稿冲刷最多占 1 个槽位；有空槽位时先发送前台请求。已发送写请求保持顺序、内容和幂等键。
- 答题进度通过 `progress-commands` 入队，受理后每秒读取当前命令回执；遇到网络失败沿用退避预算。收到 `202` 保留草稿，落库确认后只清理对应序号。常规同步状态留在业务层，页面仅在保存失败或需要处理时提供提示与重试。详细协议见[同步与监控](sync-monitoring.md)。
- 搜索输入分别按首页 300 ms、题库 250 ms 合并。失效搜索结果被忽略；目录加载失败重试当前页，成功后才继续后续分页。
- `onShow` 恢复官方绑定，`onHide` 和 `onUnload` 销毁绑定。隐藏期间停止共享状态订阅，卸载后拒绝页面更新。
- 页面进入和路由点击没有固定等待；区域请求显示本区域状态。收藏按钮和交卷分别显示保存、提交状态。

## 游客与本机试答

游客目录、搜索和单题只读取已发布且启用的内容；管理信息和个人记录沿用认证。题目列表不显示答案，已下载试答的判题数据留在业务层。普通练习、背题、模拟考试共用两次额度；已开始练习退出后保留记录与已用次数。下载超时、失败或存储失败均不进入答题、不扣次数。

`qandaTrialPractice` 使用格式版本 1，在一次本机写入中保存快照及累计记录。恢复、回看、交卷和简答自评复用答题模型，离线完成；服务端快照接口只读取题库。账号切换保留该记录，清除小程序全部数据或更换设备会重新获得额度。第三次创建引导登录，登录返回原题库配置后创建正式练习；试答结果保留在本机。

## 顶部和布局编辑

首页、题库、复盘、我的四个 Tab 使用统一状态栏和胶囊尺寸计算，底栏入口等宽排列。首页使用蓝色头部，其余页面使用白色页头。首页学习入口下方常驻答题卡片：当前设备有未完成练习时继续答题，否则联动选择最近科目和题库创建新答题；没有练习记录时进入题库。

`bank-detail` 是题库 Tab，保留页内标题和左右分栏。学院、专业、年级以一行原生选择器放在搜索框下方，长名称省略显示；每项的“全部”选项用于清除对应条件。搜索框旁的按钮重置筛选或恢复上次条件，首次未筛选时不可用。跨页定位通过待处理目标与 `switchTab` 传递，分享按公开 ID 补读内容，不受接收者本机分类筛选限制。各 Tab 滚动内容保留底栏和安全区间距。

二级及更深页面统一使用白色页面、导航和窗口底色。错题与收藏的统计卡、筛选项和题目卡使用浅灰底，保留内容层次。游客复盘的标题与内容一起模糊，加深遮罩从状态栏背景覆盖至页面底部；登录提示位于底栏上方，底栏保持可用。时间、电量和右上角胶囊由微信原生层绘制，保持系统显示。

首页的“我的错题”“我的收藏”和考试倒计时入口每次点击都读取当前登录状态：游客进入登录页，已登录用户进入对应功能。公开目录与游客试答沿用各自的访问规则。

答题与布局编辑共用 `templates/practice-*.wxml` 和 `styles/practice.wxss`。题目信息、题干、作答区、工具栏通过稳定节点的 CSS `order` 排序；导航、进度和上一题/下一题固定。答题态整页固定，题干与作答各自限高并在区域内滚动；阅读材料位于独立原文区。布局编辑提供与实际分配规则一致的比例预览，保留正文滚动和模块拖拽，底部提供恢复默认与保存；WXS 更新拖拽位移，边缘触发自动滚动，取消复位，存储失败保留草稿。

答题可分配高度扣除导航、进度、题目信息、工具栏、底部操作、安全区、提示条和间距后计算。题干与作答按本机 `practiceStemPercent` 分配，默认各占 50%，题干范围 30%～70%、步长 5%；填空将作答份额合并到题干。旧版三分区配置读取时提取题干与作答相对比例，旧排序保留其他四个模块的相对顺序。分区不随内容长短收缩；选项组在作答区内靠底排列，内容超出高度时自然滚动。

布局编辑按实际预览容器高度计算，扣除固定模块、各模块的边框、内边距及外边距，将剩余空间完整分给题干和作答；窗口变化后重新测量。比例与顺序统一保存，保存失败保留草稿，恢复答题习惯保留布局。

即时反馈确认客观题答案后，按自动打开解析偏好在答题内容区顶部的 TopSheet 半屏展开；下拉把手可继续展开至内容区的 70%，标题保持在顶部，正文随可见高度独立滚动。把手上推收起，点击可收起或重新半屏展开。入口仅在该题答案允许揭晓且已确认时存在，草稿及统一反馈过程隐藏把手；关闭自动打开解析时保留手动入口，展开后显示完整答案与解析。答对自动跳题时等待 0.8 秒且不自动展开，手动操作取消跳题；末题不自动跳转，回看已答题按开关展开且不重新计时。背题直接在题干阅读区展示答案与解析。面板使用 root-portal，以实际内容区矩形定位，不参与分区高度分配。收起后仅在中间显示把手，两侧透明露出元信息；把手随面板可见高度移动。切题重置位置，隐藏页面关闭浮层，手动操作把手取消待执行的自动跳题。

阅读材料独立展示，小题面板初始收起，点击或上滑把手展开至内容区约 70%，上方原文与下方小题独立滚动；下滑把手或点击收起。小题内部复用相同题目模板、分区和模块排序；按材料修订统计本卷小题数量，分别展示全局与组内进度。同材料切题保留原文位置和面板状态，换材料重置；展开状态只保存在页面。

窗口、字号、材料图片加载和解析显隐变化时重新测量，计时刷新不触发布局测量。连续阅读小题保留同一材料的阅读位置，换材料回到顶部；题干、作答与解析换题归零。键盘出现时，材料与解析暂时收起，当前输入区域优先；极小空间下简答题暂时收起题干，填空保留题干输入，工具栏按空间暂时收起，题号与底部操作保留。窗口已随键盘缩小时不重复扣减，收起键盘后恢复分区和阅读位置。结果汇总和独立题目详情沿用各自的阅读布局。

## 原生路由和弹层

`utils/navigation.js` 统一调用 `wx.navigateTo`、`wx.switchTab` 等原生路由。一次跳转未完成时拦截重复点击，失败后释放状态并允许回退路由；旧跳转的完成回调不能释放新跳转的锁。

共享 `bottom-sheet`、答题卡及提交遮罩使用 `root-portal`。题库配置和预设编辑共用 `bottom-sheet`，头部关闭图标保持 44 × 44px 热区。带固定底栏的面板使用 85vh 高度，表单占用扣除标题、底栏和安全区后的剩余空间，在 `scroll-view` 内滚动，内边距由滚动内容容器承担；滚动视口裁剪溢出内容，底部操作通过独立的 footer 插槽固定。首页搜索由根节点承载。普通弹层层级为 10000，提交遮罩为 10010；遮罩接收点击和触摸。底栏保持显示、随背景变暗，弹窗打开时由遮罩阻挡点击。关闭、切页及卸载统一释放弹层状态。

题库配置、首页搜索和公告内容通过 `portal-theme` 显式声明颜色变量；提交加载组件提供自身颜色默认值。`root-portal` 在 WebView 下的样式继承边界见 [Tencent TDesign 说明](https://github.com/Tencent/tdesign-miniprogram/blob/develop/packages/tdesign-uniapp/site/docs/dark-mode.md#特殊组件适配深色模式)，验收需检查主按钮、选中项、加载转圈及文字的实际颜色。

首屏内容直接呈现，移除了逐项入场延迟。点击反馈和已确认的公告喇叭动画保留。返回首页后，仍有未读公告时，喇叭继续提示。

全小程序的按压反馈使用统一节奏：触摸立即开始，松手后保留 80 ms；列表行轻微改变底色，卡片、按钮、标签和图标轻微改变透明度。按压时保持位置与尺寸稳定，持续选中、表单校验和答题对错各自保留对应颜色。共享规则放在 `app.wxss`，底栏、章节行和答题卡组件维护相同的反馈方式。`preview-my.cjs` 提供静止与按压状态的并排预览。

## 接口调用

| 能力 | 调用约束 |
| --- | --- |
| `GET /me/learning-overview` | 聚合读取学习计数、时长、可见目录总数、最近可续答摘要；页面用答题/正确计数计算正确率 |
| `GET /me/question-collections/summary?kind=WRONG/FAVORITE` | 集合统计包含筛选计数、科目/题库分布；与列表分页分开 |

## 账号注销与协议

`account-deletion` 根据当前会话使用邮箱验证码、微信身份或固定测试登录码复核，再明确确认删除。删除完成后清理当前账号的缓存、快照和队列；本机清理失败留下不含凭据的完成标记，下次启动继续清理。

`legal` 为登录页提供可直接打开的协议和隐私正文；我的页复用同一正文。

## 下拉刷新反馈

首页、题库、复盘和我的在底栏上方共用半透明轻提示，立即显示“正在刷新”，请求结束后显示完成时间或重试提示。重复手势合并同一轮刷新，页面隐藏或卸载后清理状态并拒收迟到的提示。题库左右两个 `scroll-view` 使用原生 refresher，与整页下拉共用入口；首页刷新同时等待群码重新获取和图片预检。隐藏的群码组件保留实例，便于后续刷新恢复卡片。

## 首页与题库刷新

没有可用内容时，首页最近练习区域和题库目录显示骨架占位。同账号刷新保留已有内容，首页保留当前科目与题库选择；题库按已加载的科目及题库页数重新获取，章节读取结束后更新展示。失败时保留可用内容及区域重试提示，切换账号或筛选后重新依据当前范围投影。

题库筛选切换在失效目录缓存前保留当前展示，新结果完成后替换，期间保留滚动节点并暂停旧结果操作。左栏支持下拉手势并隐藏原生加载标识，右栏展示加载反馈。
