# 题库工作台设计与实现说明

更新日期：2026-11-01。工作台保留按课程组织题库、题库详情与编辑抽屉，界面通过 HTTP Gateway 调用后端。

## 工作区与维护

`/question-banks` 左侧为课程分页，右侧为题库分页；`/question-banks/:id` 按需读取目标题库、所属课程、章节计数及当前页题目。搜索、题型、状态、章节和未分章筛选由服务端处理。

超级管理员可维护所有课程、开放名单和题库。题库维护者用于标识分工，不限制管理员访问。课程开放以整门课程为单位，包含后续新增的已发布题库。

课程和题目使用“停用”，题库使用“下架”“归档”，章节只允许删除空章节。已发放练习固定题目和材料修订，历史记录与反馈快照保留。题库所属课程固定，章节调整保持题目归属校验。

## 题型与附件

| 内容 | 编辑及判题规则 |
| --- | --- |
| 单选、多选 | 选项键与正确答案对应，多选提交确认后显示反馈 |
| 判断 | 网络合同使用布尔 `correctValue` / `answer.value` |
| 填空 | 1–20 空，每空 1–20 个答案；`{{1}}` 等标记对应空位；`blankMatch` 控制忽略大小写、首尾空白；全部空位正确才计整题正确 |
| 简答 | 参考答案、自评；评分要点可空，最多 30 条 |
| 阅读 | 1–50 道基础小题，稳定 UUID，材料与小题修订固定；材料不计题数 |

正文和解析使用纯文本与换行，图片通过独立 `assetIds` 引用。每项最多 20 张附件，上传 PNG/JPEG/WebP，单张最多 5 MiB，后端规范化为 PNG 并检查内容可见性。小程序创建练习前完整下载附件，成功持久化后进入练习。

普通练习、背题和模拟考试按完整阅读组抽题，组内顺序固定；错题和收藏复习可只选小题并携带材料。最多 1000 道作答题，容量不足容纳下一组时停止。范围预览的选题 ID 与内容版本用于创建快照。

## 范围与发布

全校开放或多组学院／专业／当前年级条件二选一；组内同时匹配，组间满足任意一组。年级为固定五档。已选分类用点查补名称，选择器打开后分页读取。

草稿可暂缺说明、解析和范围。发布检查统一校验课程、范围、章节、题型、答案、解析及有效题数。已发布内容的编辑与导入执行相同标准；最后一道有效作答题需要先下架才能停用。写操作携带业务版本，冲突后保留输入并提示重新读取。

## JSON 导入

支持多文件预览、顺序调整和统一章节。每批最多 **3000 道实际作答题、8 MiB UTF-8 JSON 请求体**；阅读组按小题计数。最多选择 20 个文件，整批校验后在事务内写入。修改内容后重新预览，响应丢失以原请求体和幂等键重试。

六种格式示例随界面提供；阅读小题标识在解析阶段固定，再次提交保持同一 ID。重复 ID、无效题型、跨题库附件和超限内容由前后端校验。失败时保留预览及输入。
