# 用户 Excel 数据管理

在用户管理页面下载模板、预览、导入或按筛选条件导出用户。每批最多 3000 行。导入冲突按文件和行号显示，修正后可重新预览。重复提交同一文件返回已有回执。

## 用户模板

使用 `.xlsx` 文件中的“用户”工作表，按模板保留表头。邮箱、昵称和记录编号必填。账号为空时由系统按文件及记录编号生成；状态填写 `ACTIVE` 或 `DISABLED`，默认正常。注册时间使用带时区的 ISO 8601，如 `2026-11-01T08:00:00+08:00`；为空时使用导入时间。

所有列按文本存储，尤其注意账号、编号、日期和前导零。导出附带只读系统编号。导入账号通过邮箱验证码直接登录，个人资料只保留昵称、头像和绑定信息。

## 接口

管理员通过 `/api/v1/admin/users/excel` 下的 `GET /template`、`POST /preview`、`POST /imports` 和 `GET /export` 管理用户数据。题库工作台使用[富媒体题库 ZIP](question-bank-import.md)。

### 旧版题库工具

已有脚本可继续使用 `/api/v1/admin/question-banks/excel` 下的模板、导出、预览与导入四个操作。新版管理端使用 ZIP。管理员可在「历史版本管理」查看各旧接口的调用数。
