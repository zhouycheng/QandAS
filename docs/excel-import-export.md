# Excel 数据管理

模板和导出文件使用“题小搭”产品名称。导入兼容原名称的 Excel 1.0 模板，仍严格校验资源类型、模板版本和表头。

管理端用户管理和题库工作台提供模板下载、导入预览、正式导入及 Excel 导出。导出覆盖当前筛选条件的全部记录。新题库导入后为草稿，完成检查后发布。

## 用户模板

使用 `.xlsx` 文件中的“用户”工作表，按模板保留表头。邮箱、昵称和记录编号必填。账号为空时由系统按文件及记录编号生成；状态填写 `ACTIVE` 或 `DISABLED`，默认正常。注册时间使用带时区的 ISO 8601，如 `2026-11-01T08:00:00+08:00`；为空时使用导入时间。

所有列按文本存储，尤其注意账号、编号、日期和前导零。导出附带只读系统编号。导入账号通过邮箱验证码直接登录，个人资料只保留昵称、头像和绑定信息。

## 题库模板

每个工作簿对应一个题库。工作表包括题库信息、章节、题目、选项、填空答案、参考要点、来源说明、附件及长文本。普通题填写题号和章节编号；阅读材料为 `READING` 行，小题通过题组编号关联，保持原顺序。多选标准选项用逗号分隔，如 `A,C`；判断答案为 `true` 或 `false`。填空候选每行一条，以空位编号区分各空。

六种题型为 `SINGLE_CHOICE`、`MULTIPLE_CHOICE`、`TRUE_FALSE`、`FILL_BLANK`、`SHORT_ANSWER`、`READING`。正文格式为 `MARKDOWN` 或 `PLAIN_TEXT`；展示方式为 `STANDARD`、`CONCEPT`、`CODE_ANALYSIS`。代码通过 Markdown 围栏指定语言，代码语言列保持空白。来源说明保存来源位置与 AI 参与元数据。

正文和解析沿用现有题库规则，简答参考答案上限为 40000 字。超过单元格 30000 个 UTF-16 单元或 200 个换行的内容自动放入长文本表，普通字段留空；片段编号从 1 连续递增，按原顺序直接拼接，不添加换行或分隔符。选项长文本用题号和选项标识定位；其他没有记录编号的关联工作表使用 `row:行号` 定位，移动这些行时需要同步调整长文本引用。

图片通过附件编号与题号关联，路径使用相对路径，例如 `assets/picture.png`。将 Excel 和图片一同选择，或按路径放入 ZIP 后上传。支持 PNG、JPEG、WebP，每张最多 5 MiB；缺失图片会阻止导入。正式提交后上传图片，事务失败时回收本次创建的文件。

## 操作步骤

1. 下载空白模板，填写后选择文件，点击“预览并校验”。
2. 检查题库、题数及逐行提示。完整题库可选择已有课程，也可勾选课程不存在时创建；追加时选择目标题库，并选择章节映射，未映射章节会新建。
3. 调整映射后重新预览。预览通过后点击“确认导入”，按提示在小程序确认本次检测。文字和附件全部通过后原子导入。新题库按分类及发布条件检查后发布。
4. 用户每批最多 3000 行；题库每批最多 20 个工作簿、3000 道作答题及 8 MiB 规范化内容。阅读小题分别计数，题组保持完整。HTTP 上传合计最多 8 MiB，附件较多时拆批处理。
5. 导出超出单批容量时自动分文件。单个 Excel 直接下载，多文件或含图片时下载 ZIP；分片题库导回时，第一片创建题库，其余片选择追加并映射已有章节。

导入只新增。邮箱、账号、系统记录或已导入文件发生冲突时，修正后再提交。同一文件的网络重试返回原结果。文件编号和记录编号保持稳定；不同记录编号即使题面相同也各自保留。已完成文件需要修正内容时，通过现有管理页面编辑。

## 接口与权限

`/api/v1/admin/users/excel` 与 `/api/v1/admin/question-banks/excel` 下提供 `GET /template`、`POST /preview`、`POST /content-safety`、`POST /imports`、`GET /export`。全部要求管理员身份。预览及导入以 multipart 字段 `files` 接收文件，`options` 为映射设置；正式导入在事务内重新校验权限、内容版本和冲突。错误清单可从预览界面下载。

导入回执和审计复用现有表。公式、宏和外部工作簿链接不进入导入流程。凭据不进入 Excel 导出。

## 部署顺序与准备状态

1. 后端应用版本为 `1.0.0`，使用统一 V1 数据库结构。按发布流程备份并执行 `schema-init`，初始化空库或校验既有 V1。
2. 更新服务器 `qanda-db` 脚本，确认帮助只列出 `export`、`restore`，检查 `sql`、`psql` 返回失败。保留空库恢复及备份流程。
3. 发布管理端和小程序，验证模板下载、合成样例预览及邮箱验证码登录。真实邮件投递由获授权的运维人员检查。
4. 正式导入时先导用户，再分批导题库，核对数量、账号状态、答案、长资料及适用范围后发布题库。

本地交付包含代码、离线 Excel 包及验证记录。服务器脚本关闭状态、邮件投递和真机交互以部署后的回读结果为准。真实旧数据的写库结果在正式导入后核对。
