# 首页公告动效

首页喇叭采用「轻抬招呼」：短暂蓄力后轻抬，经过两次递减回弹回到原位，停稳后再次循环。有可见公告时持续循环，无公告时静止。「公告」标签与点击热区保持固定。

## 动作参数

每轮 3.6 秒，缓动为 `cubic-bezier(0.4, 0, 0.2, 1)`。旋转中心在图标的 `42% 62%`，使动作围绕喇叭主体展开。

| 时间 | 动作 | 位移 / 旋转 / 缩放 |
| --- | --- | --- |
| 0–288ms | 停稳 | 0 / 0° / 1 |
| 504ms | 蓄力 | 1rpx / −3° / 0.98 |
| 864ms | 轻抬 | −5rpx / 6° / 1.04 |
| 1188ms | 回弹 | −2rpx / −2.5° / 1.01 |
| 1476ms | 收势 | −1rpx / 1° / 1 |
| 1800–3600ms | 停稳 | 0 / 0° / 1 |

图标保持 108rpx，热区保持 96 × 96rpx。按压只改变入口透明度至 0.82，旋转与缩放由图标自身的动画控制。入口继续调用 `handleAnnouncementTap` 打开公告弹窗并读取公告。

## 独立预览

在 `apps/miniapp/` 执行：

```sh
node scripts/preview-home.cjs notice
node scripts/preview-home.cjs configured
```

生成的 `.tmp-preview/home-notice.html` 和 `.tmp-preview/home.html` 分别展示有公告与无公告状态，采用真实 WXSS 和 375 × 812 首页比例。可按压入口并打开、关闭样例弹窗；浏览器预览的弹窗交互使用本地样例，业务链路由小程序自检覆盖。


## 验证

`home-prototype.check.js` 检查有公告时持续循环、空公告时静止及公告入口连接；官方编译检查覆盖首页 WXML 和 WXSS。当前整体验证结果见[验收规范](verification.md)。

预览时核对标签和热区坐标、周期首尾、图标与搜索框及胶囊的遮挡、按压透明度和弹窗开关。浏览器预览、官方编译与微信真机表现分别验收；设备帧率和触控需在真机记录。
