# 首页公告动效与阅读

喇叭有未读公告时按 1.6 秒循环放大摇晃，峰值 1.2 倍、左右 16°，45% 周期后停稳。弹窗打开时暂停。图片、位置、标签和热区保持原布局。

公告采用居中面板，固定横向标签栏与独立滚动正文。胶囊按标题自然收紧，两侧留 10px，最大宽度 104px，可见高度 32px、触控高度 44px；标题保持单行，过长省略。胶囊之间间隔 6px，日期与正文间隔 4px。正文从日期开始，标题由选中的胶囊呈现，置顶优先；Top 优先于 New，New 按更新时间只标记最新一条。第一页 20 条，横滑末尾加载下一页，失败保留内容并原页重试。

角标使用内置 imagegen 生成透明 PNG：黄色圆润斜体字、深蓝描边、珊瑚红外边与奶油白轮廓。Top 以已选定的 New 图片为参考，仅替换文字。素材位于小程序 assets/home/announcement-top.png 与 announcement-new.png。

运行 node scripts/preview-home.cjs modal 预览横向切换。构建与自检覆盖编译及业务状态，设备触控、帧率和小尺寸可读性需真机确认。

公告正文显示时按账号、公告 ID 和版本记录本机已读；所有可见公告已读后静止，新公告和更新版本重新提示。首页按每页 20 条读取完整可见列表以核对历史未读，复用 60 秒缓存；正文分页切换保留完整索引。存储失败时保留未读提示。已读记录仅在当前设备保存。
